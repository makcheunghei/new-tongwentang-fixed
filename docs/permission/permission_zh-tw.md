# 新同文堂（修復）需要的授權項目

本擴充功能只申請目前功能實際需要的權限。

## 必要的授權

- `contextMenus`
  - 建立工具列圖示及網頁右鍵選單。
- `notifications`
  - 顯示剪貼簿轉換結果及錯誤訊息。
- `storage`
  - 儲存偏好設定、網域規則及自訂轉換詞彙。

內容腳本需要 `<all_urls>` 主機存取權，因為網頁轉換功能必須在使用者瀏覽的頁面上執行。

## 選擇性的授權

- `clipboardWrite`
  - 將轉換內容寫回剪貼簿。
- `clipboardRead`
  - 從剪貼簿讀取欲轉換內容。

剪貼簿權限只會在使用者選擇剪貼簿轉換指令後要求。
